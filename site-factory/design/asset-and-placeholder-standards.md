# Asset and Placeholder Standards

Describe each asset by role, placement, intended composition, aspect ratio, responsive crops, licensing/approval, file format and alt text. Use real screenshots and approved photos only when supplied; conceptual mockups must be labeled. Do not invent customer photos, logos, product capabilities or endorsements.

| Asset | Starting size | Brief and alt guidance |
| --- | --- | --- |
| Hero | 1600 x 1000 | Describe the offer in use; concise contextual alt |
| Product screenshot | Actual UI ratio | Capture approved UI; describe meaningful content |
| Founder photo | 800 x 1000 | Real approved photo; identify person only if provided |
| Logo | Source vector | Approved mark and organization name; no invented brands |
| Avatar | 160 x 160 | Real approved photo or omit; avoid redundant alt |
| Process | 1200 x 600 | Supply equivalent text steps |
| Open Graph | 1200 x 630 | High contrast; verify cropping and public URL |

Dimensions are design starting points, not requirements. A placeholder should read `[Insert approved hero image: 1600 x 1000, showing ...]`; record owner and replacement checklist. Decorative images use empty alt; do not publish broken placeholder URLs.
