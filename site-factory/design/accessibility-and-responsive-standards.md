# Accessibility and Responsive Standards

- Use semantic landmarks, a logical heading order, accessible names, labels and actionable error messages.
- Ensure keyboard operation, visible focus, appropriate reading order and focus return after dialogs. Do not trap focus outside a modal.
- Test contrast for text, controls and focus indicators against applicable WCAG requirements; do not rely on color alone.
- Support zoom, reflow and small screens; test narrow and wide viewports, touch interaction, long content and localized labels.
- Respect `prefers-reduced-motion`; never require animation to understand information.
- Use descriptive alt text for informative images and empty alt for decoration. Avoid text embedded in imagery.
- For embeds use meaningful iframe titles and keyboard access; ensure resizing and errors are communicated.
- Test with automated tools and manual keyboard and screen-reader checks. Catalog selection does not establish compliance.
