# Site Factory Specification Library

This library specifies a future launch factory; it does not implement a generator, deploy projects, or connect providers. Start with [integration-map.md](integration-map.md), then [architecture.md](architecture.md) and [roadmap.md](roadmap.md).

Choose a project type in [template-catalog.md](template-catalog.md), a style in [design/style-selection-guide.md](design/style-selection-guide.md), and describe the launch using [schemas/project-brief.schema.json](schemas/project-brief.schema.json). The five [examples](examples/README.md) demonstrate the contract.

Catalogs use stable IDs and version 1.0.0. IDs are references, not evidence that a feature exists. Templates are design specifications; existing HTML templates are identified in the integration map. Verify a deployment and provider configuration separately.
