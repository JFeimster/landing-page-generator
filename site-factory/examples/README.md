# Example Project Briefs

These examples are fictional planning inputs, not deployed products. Each conforms to `../schemas/project-brief.schema.json`; provider and content placeholders must be replaced before launch.

- `saas-waitlist.json`: static SaaS landing page with a configured form.
- `local-service-funnel.json`: estimate-request funnel.
- `niche-directory.json`: searchable, curated listing experience.
- `dashboard-app.json`: authenticated server-backed portal.
- `embedded-calculator.json`: host-embedded tool with a supplied formula.

A future generator should additionally check that template, runtime, capability dependencies and design catalog references are compatible; JSON Schema alone does not resolve all cross-file relationships.
