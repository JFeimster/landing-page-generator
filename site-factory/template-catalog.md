# Template Catalog

All factory templates below are proposed specifications. Existing single-file examples are listed in [integration-map.md](integration-map.md).

| ID | Specification | Best fit |
| --- | --- | --- |
| static-site | [static-site.md](templates/static-site.md) | Prebuilt marketing and documentation |
| landing-page | [landing-page.md](templates/landing-page.md) | Single-offer conversion |
| funnel | [funnel.md](templates/funnel.md) | Multi-step acquisition |
| nextjs-app | [nextjs-app.md](templates/nextjs-app.md) | Authenticated product |
| directory | [directory.md](templates/directory.md) | Searchable listings |
| dashboard | [dashboard.md](templates/dashboard.md) | Operations or client portal |
| api-oauth | [api-oauth.md](templates/api-oauth.md) | API or delegated integrations |
| embed-widget | [embed-widget.md](templates/embed-widget.md) | Host-embedded tool |
| single-file-html | [single-file-html.md](templates/single-file-html.md) | Portable standalone page |

Project types are catalog IDs; a project type may select a compatible template rather than sharing its filename. See [catalogs/project-types.json](catalogs/project-types.json).
