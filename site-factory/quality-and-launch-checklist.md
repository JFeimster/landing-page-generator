# Quality and Launch Checklist

A template is ready when its defined checks pass, not simply when files are generated.

- [ ] Audience, goal, CTA, scope and destination are unambiguous.
- [ ] User-supplied claims, price, guarantee, deadlines and approved assets are traceable; missing items are labeled.
- [ ] All primary interactions work with keyboard, visible focus, accessible names and reduced motion.
- [ ] Mobile layout has no horizontal overflow; text, touch targets and media remain usable.
- [ ] Titles, descriptions, canonical URL and sharing images are correct where relevant.
- [ ] Forms validate on the server where applicable, report errors and use a real submission destination.
- [ ] Auth, authorization, secrets, input validation and rate limits are tested for server-backed products.
- [ ] Embed origin checks, versioning, sizing and error behavior work in a host-page test.
- [ ] Event delivery and consent are verified; no sensitive personal data enters analytics.
- [ ] Production build, meaningful tests, previews, broken-link and performance checks pass.
- [ ] Domain, data migrations, backups, monitoring, ownership and rollback are documented.
- [ ] Every placeholder is resolved or intentionally blocked from release.
