# Contributing

Contributions should improve the GPT's ability to create clear, ethical, conversion-focused landing pages.

## Contribution areas

- Knowledge files
- Copy frameworks
- HTML templates
- Action schemas
- TypeScript Action implementations
- Examples
- Tests
- Documentation

## Guidelines

- Do not add fabricated proof, testimonials, statistics, media mentions, customer logos, endorsements, pricing claims, legal claims, or scarcity.
- Keep examples realistic and clearly labeled.
- Prefer practical implementation guidance over abstract theory.
- Keep generated HTML accessible, responsive, maintainable, and fast-loading.
