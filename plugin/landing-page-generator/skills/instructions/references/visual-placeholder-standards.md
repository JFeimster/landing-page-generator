# Visual Placeholder Standards

## Purpose
Define how the GPT should specify visuals without inventing real assets or brands.

## Hero Image Rules
- Use one primary hero image or mockup.
- Describe what the image should communicate.
- Include dimensions when possible.
- Keep the image aligned with the offer promise.

## Product Screenshot Rules
- Show only real product screens or clearly marked mockups.
- Label the placeholder if the screenshot does not exist yet.
- Do not fake UI states that imply actual product functionality.

## Founder Photo Rules
- Use only a real founder or team photo supplied by the user.
- If unavailable, use `[Founder photo placeholder]`.

## Customer Logo Rules
- Use approved logos only.
- If not available, use `[Customer logo placeholder]`.

## Testimonial Avatar Rules
- Use a real avatar only when the testimonial is real and approved.
- Otherwise use text-only testimonials.

## Feature Icon Rules
- Keep icons simple and semantic.
- Icons should support scanning, not replace explanation.

## Process Diagram Rules
- Use diagrams to show steps, not decoration.
- Keep labels short and concrete.

## Problem Illustration Rules
- Illustrate the pain point honestly.
- Do not exaggerate distress or invent conditions.

## Offer Stack Graphic Rules
- Show deliverables, bonuses, or inclusions.
- Do not show items that are not actually included.

## Comparison Graphic Rules
- Compare only against factual alternatives.
- Avoid misleading "vs. everyone else" framing.

## Background Pattern Rules
- Use subtle patterns only.
- Do not compete with the copy.

## Mobile Image Behavior
- Images should scale down cleanly.
- Important text should not be embedded in images.

## Alt Text Rules
- Describe the function or content of the image.
- Example: "Screenshot placeholder showing the hero section layout."

## File Naming Conventions
- Use lowercase with hyphens.
- Example: `hero-mockup-desktop.png`
- Avoid spaces and ambiguous names.

## Recommended Dimensions
- Hero image: 1200x900 or similar
- Social share image: 1200x630
- Logo strip assets: consistent height
- Product screenshots: use the actual UI ratio when possible

## Placeholder Wording
- `[Insert hero image]`
- `[Add founder photo]`
- `[Add product screenshot]`
- `[Insert approved logo row]`

## Designer Handoff Brief Template
- Asset name
- Purpose
- Placement on page
- Required dimensions
- Alt text
- Notes on tone
- Any prohibited elements

## Hard Rules
- Do not instruct the GPT to fabricate real logos, awards, customer photos, or screenshots.
- If the asset does not exist, label it as a placeholder.
