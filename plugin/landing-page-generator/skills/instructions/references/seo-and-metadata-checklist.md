# SEO And Metadata Checklist

## Purpose
Ensure the HTML phase includes metadata and structural signals that support search, sharing, and accessibility.

## Required Metadata
- Title tag
- Meta description
- Canonical URL placeholder
- Open Graph title
- Open Graph description
- Open Graph image placeholder
- Twitter/X card tags
- Robots tag when needed

## Heading Hierarchy
- One H1 only
- H2s for major sections
- H3s for subsections
- Do not skip heading levels without reason

## Image Alt Text
- Describe the image function, not just appearance.
- Include context when the image supports understanding.
- Do not stuff keywords.

## Internal Anchor Links
- Use jump links for long pages.
- Link hero CTA to the main form or offer section.
- Include a back-to-top anchor if the page is long.

## Schema Suggestions
- Organization
- LocalBusiness
- Product
- Service
- FAQPage
- Course or EducationalOrganization when relevant

## Page Speed Basics
- Keep HTML lean
- Limit script dependencies
- Use compressed images
- Avoid layout shifts
- Load critical content first

## Accessibility and SEO Overlap
- Semantic tags help both screen readers and search engines.
- Clear headings help both scanning and indexing.
- Strong alt text helps both usability and image search.

## Local Business Considerations
- Include service area
- Include location references if relevant
- Add phone, hours, and map placeholder if appropriate
- Use local intent keywords naturally

## SaaS Considerations
- Include use case terms
- Include integration names only if supported
- Use mechanism and feature language clearly

## Course / Coaching Considerations
- Include transformation language
- Include curriculum or process sections
- Use FAQ to address fit, format, and access

## Ecommerce Considerations
- Include product name, category, and key benefit
- Include shipping, returns, and materials when relevant
- Add product schema where applicable

## Common Mistakes
- Missing meta description
- Overlong title tags
- Broken heading order
- Duplicate alt text
- Fake social proof in metadata
- Missing canonical placeholder

## Example Metadata Snippet
```html
<title>Landing Page Generator for High-Converting Pages</title>
<meta name="description" content="Generate complete landing page copy and responsive HTML with clear proof, ethical persuasion, and mobile-first design." />
<link rel="canonical" href="[canonical-url]" />
<meta property="og:title" content="Landing Page Generator" />
<meta property="og:description" content="Create conversion-focused landing pages with structured copy and clean HTML." />
<meta property="og:image" content="[open-graph-image-url]" />
<meta name="twitter:card" content="summary_large_image" />
```

## Final Pre-Export Checklist
- Title exists and fits the page intent
- Description clearly states the offer
- Canonical placeholder is present
- OG tags exist
- Headings are logical
- Alt text is present
- Schema is suggested where relevant
- No metadata contains fabricated claims
